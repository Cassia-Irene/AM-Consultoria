Projeto: Este projeto visa desenvolver um sistema de banco de dados completo para organizar as informações dos clientes da empresa do Adriano, que atualmente são registradas de forma dispersa entre cadernos, planilhas e WhatsApp. O objetivo é criar uma estrutura centralizada, confiável e flexível para gerenciar dados de clientes, contatos, contratos, pendências, histórico de pagamentos, eventos críticos, relatórios e indicadores.
